# v0.2 验证记录

日期：2026-10-20。环境：macOS 15.8.1 (24H212)，Darwin 24.6.0 arm64，Python 3.9.6。

## 实际已执行

- 计算测试：23 项。固定积压与并行工位、原始下单时间、待确认、制作剩余进度、事件去重/完成/冲突、原始人数不直接加单、路程内完成/新增订单、零售挑选期间队伍消退/增长、同拥挤档样本门槛、缺失/过期降级、断流/恢复的模拟快照、非法数值和时间。
- 本机 HTTP 测试：7 项。静态页面资源、无 Token/错误 Token/非 ASCII Token、Host/Origin 拦截、完整 JSON 试算、错误类型/超长/深层 JSON、模拟预设、文件路径不可任意读取。
- 浏览器手工检查：本机界面成功显示餐饮三类卡片；浮动比例调整为 0 后预订结果为 13.5–13.5 分钟；页面在快照过期后自动隐藏总 ETA，明确显示各数据过期原因；刷新模拟快照后恢复试算。

测试命令（在本仓库）：

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 run.py serve
```

Windows 待执行：

```powershell
$env:PYTHONPATH = "src"
py -3 -m unittest discover -s tests -v
py -3 run.py
```

测试不会访问互联网、相机或云服务。HTTP 测试只短暂监听 127.0.0.1 随机端口。受限开发沙箱最初拒绝本机监听；在获准启动本机服务后完成验证，未改为对局域网监听。
